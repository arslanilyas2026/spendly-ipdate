# Project Memory

## Core
React PWA/Capacitor for Android. NO backend or login.
100% local IndexedDB storage. JSON manual backups.
Mobile-only layout (360px-430px). Plus Jakarta Sans body & headings.
Warm premium theme: amber accent, cream bg light, charcoal dark.
4-tab nav: Home, Transactions, Reports, More. FAB for add transaction.
